EigenFlow Profiler

Unsupervised attack-type classification using K-means cluster images and PCA eigenprofiles — revised pipeline with honest results and 6.27× benign separation.

Project Overview

Traditional signature-based detection misses novel and subtle threats by design. This project takes a fundamentally different approach: instead of learning from labeled attack signatures, it learns what each attack family looks like structurally — and flags anything that doesn't fit.

Inspired by the "eigenfaces" technique in facial recognition, the pipeline encodes each NetFlow attack file as a series of K-means cluster-boundary images, trains group-specific PCA eigenprofile models on those images, then classifies new traffic by measuring which group's model reconstructs it with the lowest L2 error. No labels are required at inference time.

Source data is the CIC-IDS-2018 dataset (Canadian Institute for Cybersecurity / University of New Brunswick) — ten parquet files covering four attack families across multiple days of simulated enterprise traffic. This page reflects the revised pipeline, which corrects several critical inconsistencies in the original implementation and reports more honest results: 70% test classification accuracy and a 6.27× benign separation ratio.

Pipeline Revision

The original implementation contained several bugs that made its results invalid. The revised notebook addresses all of them:

  • Consistent image size (Fix 1): The original mixed 300×300 images at training with 100×100 at inference. The fix uses a canonical 100×100 throughout — training, test generation, and benign classification all use the same dimensions.
  • Serialized models, never re-fit (Fix 2): The original re-fit PCA from scratch on the full training directory every time a single image was classified. The fix serializes each fitted PCA object with joblib and loads it at inference.
  • Single shared scaler (Fix 3): The original benign rejection test used clip(x, 0, 255) / 255, which clipped large NetFlow values (byte counts, durations that routinely exceed 255) and produced a fundamentally different distribution from what the models were trained on. The fix fits one MinMaxScaler once and uses it everywhere.
  • K-means fit once, reused (Fix 4): The original re-fit K-means separately for the scatter points and the mesh background, creating color mismatches. The fix fits once and calls .predict() for both.
  • Relative noise augmentation (Fix 6): Augmentation noise is now scaled to 5% of each PCA dimension's standard deviation rather than a fixed absolute value, making it consistent regardless of data spread.

The corrected pipeline reduces the apparent benign error from ~60,000 (an artifact of the normalization mismatch) to ~21,000 — a more honest result that still clearly separates benign from attack traffic.

How It Works

Step 1 — Shared Normalization

A single MinMaxScaler is fitted once on a 20,000-row representative sample (5,000 rows from one file per attack group) and serialized. All subsequent pipelines — training images, test images, and benign testing — use this same fitted scaler, ensuring the eigenprofiles and inference operate on the same feature distribution.

Step 2 — Stratified Sampling

Each source file is balanced across label classes using a pandas stratified sample capped at 10,000 rows per class. This replaces RandomOverSampler and prevents memory exhaustion on heavily imbalanced files (e.g. Web1-Thursday: 829,883 benign vs 341 attack rows).

Step 3 — K-means Cluster-Boundary Images

The scaled feature matrix is compressed to two dimensions via PCA. A single K-means (k=3) model is then fit on the 2D projection and reused for both scatter point labels and mesh-grid background, ensuring colors are always consistent. The resulting cluster-boundary plot is saved as a 100×100 grayscale PNG — the visual "fingerprint" of that attack's structure. Five augmented images per file are produced by injecting relative Gaussian noise before clustering.

Step 4 — Eigenprofile Training

Augmented images are grouped by attack family. For each of the four groups, all images are converted to grayscale, resized to 100×100, flattened into 10,000-dimensional vectors, and a PCA model (5 components) is fit on the group's image matrix. The resulting principal components — the "eigenprofiles" — are serialized with joblib for reuse at inference.

Step 5 — Reconstruction Error Classification

A new flow image is projected onto each group's 5-dimensional eigenspace and reconstructed. The L2 norm between the original and reconstructed image is computed for each group — the group yielding the lowest error wins. For benign rejection, raw NetFlow rows are normalized with the shared scaler and zero-padded to 10,000 dimensions before projection.

Results

Classification Accuracy — 70% (21/30)

Application (6/6), Credential (3/3), Botnet (3/3), and Infil2 (3/3) all classify correctly with low, stable reconstruction errors. The misclassifications are systematic rather than random: DDoS1-Tuesday and DoS1-Thursday (6 images) are consistently predicted as exploit — their cluster-boundary images visually resemble the exploit group's training data more than the other denial files. Infil1-Wednesday (3 images) is consistently predicted as application — low-rate infiltration traffic can produce 2D cluster patterns geometrically similar to web application traffic. Notably, misclassified files show errors of 4,900–5,540 vs. correctly classified denial files at 896–1,679 — the error magnitude itself is a useful anomaly signal even when group assignment is wrong.

Benign Separation — 6.27× Ratio

8,000 benign flow rows (from four source files) are passed through the shared scaler and zero-padded before projection. Mean best-group reconstruction error for benign traffic is ~21,110 vs. ~3,369 for matched attack traffic — a 6.27× separation. All four group models produce consistently high errors on benign data; none generalizes to out-of-distribution traffic. This gap enables a simple threshold-based anomaly filter: any sample with a best-group error above ~10,000 can be flagged as likely benign before reaching the group classifier.

Key Takeaways

  • Pipeline integrity matters — normalization inconsistencies inflated the original benign error by ~3× and inflated test accuracy to an unreliable 100%. Fixing them yielded honest, reproducible results.
  • 70% classification accuracy reflects real structural similarity between some attack families; the misclassifications are systematic and informative, not random noise.
  • The 6.27× benign separation ratio is the more operationally valuable result — a simple reconstruction-error threshold can reliably filter benign traffic before the group classifier runs.
  • Two lossy projections in series (77D → 2D → 100×100 image → 5D eigenspace) is a significant limitation. Replacing the first PCA projection with a supervised method like LDA would likely improve classification accuracy substantially.
