EigenFlow Profiler

Unsupervised attack-type classification using K-means cluster visualizations and PCA eigenprofiles — no labeled inference required.

Project Overview

Traditional signature-based detection misses novel and subtle threats by design. This project takes a different approach: instead of learning from labeled attack signatures, it learns what each attack family looks like structurally — and flags anything that doesn't fit.

Inspired by the "eigenfaces" technique in facial recognition, the pipeline encodes each NetFlow record as a visual image of its cluster geometry, then trains group-specific PCA models ("eigenprofiles") on those images. Classification at inference time requires no labels — only a reconstruction error comparison.

Source data is drawn from the CIC-IDS-2018 dataset (Canadian Institute for Cybersecurity / University of New Brunswick), covering nine attack files across four families: credential abuse (Brute Force), denial-of-service (DDoS, DoS), exploit/malware (Botnet, Infiltration), and application-layer (Web attacks).

How It Works

Step 1 — Flow-to-Image Encoding

Each NetFlow file's 77 numeric features are normalized with MinMaxScaler, then compressed to two dimensions via PCA. K-means (k=3) is then run on the 2D PCA projection to find the natural clustering structure within each flow set. The resulting cluster assignments and decision boundaries are rendered as a 300×300 grayscale image — a compact visual fingerprint of that attack's behavioral geometry.

Step 2 — Augmentation

To build a robust training set from a limited number of attack files, each image is augmented 5× by adding small Gaussian noise to the PCA projections before re-running K-means. This produces visually varied but structurally consistent images per attack family.

Step 3 — Eigenprofile Training

Augmented images are grouped by attack family. For each of the four groups, all images are flattened into 90,000-dimensional vectors and a PCA model (5 components) is fit on the group's image matrix. The resulting principal components — the "eigenprofiles" — capture the dominant visual structure of that attack type's cluster patterns.

Step 4 — Reconstruction Error Classification

At inference time, a new flow is encoded into an image using the same PCA + K-means pipeline. That image is then projected onto each group's eigenprofile basis and reconstructed. The L2 reconstruction error is computed for each group — the group that reconstructs the image most faithfully (lowest error) wins the classification. No labels needed.

Key Highlights

  • K-means + PCA Image Encoding: Flows are projected to 2D via PCA, clustered with K-means (k=3), and saved as cluster-boundary images — capturing attack geometry rather than raw feature values.
  • Gaussian Augmentation: 5× augmentation per file via PCA-space noise produces diverse training images from limited source data.
  • Group-Specific Eigenprofiles: Four separate PCA models (5 components each) learn the visual fingerprint of each attack family from 90,000-dimensional image vectors.
  • Unsupervised Classification: Attack type is inferred purely from L2 reconstruction error — no labels used at inference time.
  • 100% Test Accuracy: All 30 held-out test images correctly classified across all four attack families.
  • Scalable & Lightweight: PCA fitting and error-based inference are computationally cheap and suitable for high-volume SOC pipelines.

Key Takeaways

  • K-means clustering in PCA space produces visually distinct, family-specific flow fingerprints that eigenprofile models can reliably learn.
  • Gaussian noise augmentation in PCA space is an effective strategy for generating diverse training images from limited source files.
  • Reconstruction error against group-specific PCA models is a robust unsupervised classifier — 100% accuracy on 30 held-out test samples.
  • Image-style encoding of network flow data opens the door to the full computer vision toolkit for network security problems.
